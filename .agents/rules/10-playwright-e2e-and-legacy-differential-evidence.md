# Rule 10: Mandatory Playwright E2E Browser & Legacy Differential Verification Gate

1. **No Completion Claim Without Real Playwright E2E Execution (`npx playwright test`):**
   - Unit tests (`cargo test`) alone are **NEVER** sufficient to claim that a web portal, React SPA feature, Ruffle WebAssembly game integration, or in-game RPC flow works.
   - Every UI, portal, Ruffle, or RPC gameplay change MUST be verified by running the real Playwright test suite (`cd web && node ./node_modules/@playwright/test/cli.js test`) against the live `./target/debug/king-pirate serve` daemon (`http://127.0.0.1:8081`, WebSocket `:8003`, TCP `:8002`) and attaching the verbatim Playwright execution output (`X passed (Ys)`) plus screenshot/trace artifacts.

2. **5 Mandatory Playwright & Legacy Differential Assertions:**
   - **Assertion 1 — Zero `.php` Requests & Zero `.php` URLs:** Playwright network interception (`page.on("request")`) must assert `0` requests containing `.php` and `0` browser history URLs containing `.php`.
   - **Assertion 2 — Direct Ruffle WebAssembly Mount (Zero `<iframe>` Wrapper):** Playwright DOM inspection must assert `await page.locator("iframe").count() === 0` and verify that Ruffle (`<ruffle-player>` / `<ruffle-embed>` inside `#ruffle-game-container`) mounts directly in the React SPA DOM and connects to `ws://127.0.0.1:8003`.
   - **Assertion 3 — 100% Legacy LouLx Web Tools Parity (`Vua-Hai-Tac-2025-UP-LouLx`):** Playwright must verify all 4 legacy web workflows (`[4] Start Game`, `[5] GM Tool /admin_loulxgame` backed by `Console.class.php`, `[6] Fix Tool` for Hero/Blood, and `[7] Level Updater 1-200`) inside the React SPA without full-page reloads.
   - **Assertion 4 — Zero Unhandled `Main.swf` RPC Calls (`0` `_ => []` Fallbacks on Live Session RPCs):** Every RPC method emitted by `Main.swf` during login, town entry, and UI panel clicks (including `user.getSwitch` returning all `63` `SwitchDef` IDs from `legacy-ref/rpcfw/def/Switch.def.php:18-81`, `charity.fetchVipSalary`, `charity.fetchPresigeSalary`, `achievements.fetchSalary`, `bag.bagInfo`, `task.getAllTask`, `formation.getFormation`, `hero.getRecruitHeroes`, `turntable.getInfo`, `reward.getSignInfo`) must be matched against `legacy-ref/rpcfw/module/` and persisted in `DataStore`.
   - **Assertion 5 — Real-Time `babeltime.player.userModify` Push & State Persistence:** Playwright + WebSocket RPC verification must confirm that currency/state mutations (`gold_num`, `belly_num`, `cur_execution`, `prestige_num`, `vip`, `level`, `t_bag`, `t_hero`, `t_charity`) emit `babeltime.player.userModify` and survive server restarts (`data/pirate_store.amf3`).
